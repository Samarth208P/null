# NULL interface

Finance administrators use NULL on a laptop in a bright office, checking names and six-decimal amounts carefully; white surfaces and dark text prioritize long-session readability.

The color strategy is restrained. White content sits beside a light neutral navigation rail. Graphite is the main action color; an indigo anchored at hue 270 marks selection and private-zone states. Green and amber communicate outcomes and boundaries. Colors are defined in OKLCH in apps/web/src/styles.css.

Use a single system sans family with fixed rem sizes and tabular financial values. Main headings are 30px, body 14px, labels 12–13px. The NULL wordmark is typographic, with a precise slashed-circle mark. No decorative imagery is needed for the work surface.

Desktop layout has a 228px navigation rail, a compact utility bar, and a content column with generous 40px gutters. Mobile navigation becomes a dismissible drawer. Data tables scroll within their region. Panels use one-pixel boundaries, 12px corners, and no decorative shadows.

Buttons share 9px corners and clear keyboard focus. Status tags are compact and semantic. Forms show inline validation. Multi-step distributions use an ordered progress indicator. Actions that cross public privacy boundaries use explicit confirmation. Motion is limited to short state transitions and respects reduced motion.
